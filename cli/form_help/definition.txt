--from is a JSON file that holds a form definition:

  {
    "version": 1,                         always 1
    "pages":  [{"key": "main", "title": "Main"}],
    "fields": [ <field>, ... ],
    "rules":  [ <rule>, ... ],            optional; show, hide or require fields
    "defaults": {"<field key>": <value>}, optional
    "submit": {"required": ["<field key>"]}  optional
  }

A key (page, field or rule) is 1 to 40 lowercase letters, digits or _,
starting with a letter, and is unique in its list.

<field>:
  {"key": "email", "kind": "text", "page": "main", "label": "Email",
   "required": true, "hidden": false, "width": "full"}

  "description": "We reply here." is optional help text shown with the
  field (at most 500 characters).

  kind is one of: text, textarea, richtext, markdown, number, date, toggle,
  select, user, checklist, file, computed, table. A host may allow fewer:
  run `tinycld form hosts`. Options by kind:
    select:  "options": [{"value": "dev", "label": "Developer"}] (at least one),
             "display": "dropdown" (default) | "radio" | "checkbox",
             "multiple": true (people may pick more than one; shown as checkboxes)
    number:  "min": 0, "max": 10, "decimals": 2
    text, textarea: "maxLength": 200
    file:    "accept": ["application/pdf", ".docx"], "maxSizeMb": 10, "multiple": true

  A built-in field of the host uses "kind": "builtin" and its own key. Every
  built-in field of the host must be listed; `tinycld form hosts` names them.
  Web forms (core:web_form) have no built-in fields.

<rule>:
  {"key": "show_cv", "match": "all",
   "when":    [{"field": "role", "op": "is", "value": "dev"}],
   "actions": [{"action": "show", "field": "cv"}]}

  op depends on the field's kind:
    text, textarea: eq, neq, contains, starts_with, is_empty, not_empty
    number, computed: eq, neq, gt, lt, gte, lte, is_empty, not_empty
    date: before, after, is_empty, not_empty
    toggle: is_true, is_false
    select, user: is, is_not, is_any_of, is_empty, not_empty
    checklist: all_done, any_open, is_empty
    richtext, markdown, file, table: is_empty, not_empty
  action is one of: show, hide, require, set_options, set_value. show and
  hide take "field" or "page"; set_options takes "options"; set_value takes
  "value".

A default or set_value value is a literal, {"today": []}, {"me": []} or
{"addDays": ["2026-01-31" or {"today": []}, <whole days>]}.

Start from `tinycld form example definition`, or from an existing form:
`tinycld form export <form> > def.json`.
